# CashTrack

تطبيق عربي لإدارة المصروفات اليومية بثيم أخضر وأبيض، مبني باستخدام HTML وCSS وJavaScript.

## الميزات المتاحة

- إضافة المصروف وتعديله، مع التحقق من المبلغ والتصنيف والتاريخ والوصف الاختياري.
- حذف المصروف بعد التأكيد؛ الإلغاء لا يغيّر البيانات.
- تصفية المصروفات حسب التصنيف وفترة زمنية شاملة لتاريخ البداية والنهاية.
- الترتيب بالأحدث أو الأقدم أو الأعلى مبلغًا.
- تحديث القائمة والإجمالي والرسم البياني من النتائج نفسها بعد كل عملية.
- حفظ البيانات في `localStorage` واسترجاعها عند فتح الصفحة أو تحديثها.
- حالات واضحة للقائمة الفارغة ونتائج التصفية الفارغة وتعذر التخزين.

يبدأ التطبيق بقائمة فارغة وإجمالي صفر، دون بيانات تجريبية. تظهر التغييرات بعد نجاح حفظها فقط. عند فشل الحفظ تبقى القائمة السابقة، ويظل نموذج الإضافة أو التعديل مفتوحًا لإعادة المحاولة. عند فشل قراءة البيانات أو تلفها، يمنع التطبيق الكتابة فوقها ويتيح إعادة محاولة القراءة.

## التشغيل

نزّل المستودع ثم افتح `index.html` في متصفح حديث:

```bash
git clone https://github.com/amall654/CashTrack.git
cd CashTrack
```

لا يتطلب المشروع تثبيت حزم أو عملية بناء. اضغطي على «إدارة المصروفات»، ثم «إضافة مصروف». يُفضّل استخدام خادم ملفات محلي على عنوان ثابت لضمان سلوك تخزين متسق؛ سلوك `localStorage` مع فتح ملفات `file:` مباشرة يعتمد على المتصفح. عند تشغيل خادم محلي، استخدمي `localhost` لدعم توليد المعرّفات عبر `crypto.randomUUID()`.

البيانات مرتبطة بالمتصفح والجهاز وعنوان الموقع، ولا تُرسل إلى خادم أو تتزامن بين الأجهزة. قد تُفقد عند مسح بيانات الموقع أو إنهاء التصفح الخاص. يُحمّل خط IBM Plex Sans Arabic من Google Fonts عند توفر الإنترنت، مع خط محلي بديل دون اتصال.

## الملفات والمسؤوليات

```text
CashTrack/
├── index.html
├── README.md
├── css/style.css
├── js/
│   ├── expense-form.js
│   ├── expense-chart.js
│   ├── expense-ui.js
│   ├── storage.js
│   └── app.js
├── tests/
│   ├── app.test.cjs
│   └── expense-chart.test.cjs
└── docs/AMAL-HANDOFF.md
```

| الملف | المسؤولية |
| --- | --- |
| `expense-form.js` | نموذج الإضافة والتعديل والتحقق من المدخلات |
| `expense-chart.js` | تجميع المبالغ حسب التصنيف وعرض الرسم |
| `expense-ui.js` | عرض القائمة وحالات الفراغ وأزرار التعديل والحذف |
| `storage.js` | تحميل السجلات والتحقق منها وحفظها |
| `app.js` | ربط الأحداث والتخزين والتصفية والترتيب وتحديث العرض والسنة |

يُحمّل `app.js` بعد بقية المكونات، وقد أُزيل ملف المعاينة المؤقتة `landing.js`.

## شكل البيانات

```js
{
  id: 'UUID',
  amountCents: 1235,
  category: 'الصحة',
  date: '2026-09-16',
  description: ''
}
```

المبلغ عدد صحيح بالهللات؛ `1235` تعني 12.35 ريال. الحد للمصروف من 0.01 إلى 1,000,000 ريال. الوصف اختياري حتى 60 حرفًا. التاريخ محلي بصيغة `YYYY-MM-DD`. التصنيفات: الطعام والمشروبات، المواصلات، التسوق، الفواتير، الترفيه، الصحة، وأخرى. مفتاح التخزين هو `cashtrack.expenses.v1`.

يتحقق التخزين من بنية كل سجل وتاريخ فعلي ومعرف غير مكرر والمبلغ والتصنيف والوصف. البيانات غير الصالحة لا تُحذف تلقائيًا.

## الاختبارات

باستخدام Node.js:

```bash
node --test tests/*.test.cjs
```

تغطي الاختبارات حساب الرسم، بداية فارغة، بقاء الإضافة والتعديل بعد إعادة تهيئة التطبيق، تأكيد الحذف وإلغاءه، التصفية والترتيب وإعادة الضبط، وفشل القراءة والكتابة والبيانات التالفة. اختبارات الربط تستخدم محاكاة للتخزين وأحداث الصفحة؛ لا تحل محل التحقق في المتصفح.

للتحقق اليدوي: أضيفي مصروفًا ثم حدّثي الصفحة، وعدّليه واحذفيه، وجرّبي التصفية وإعادة ضبطها على الهاتف والحاسوب. تأكدي من تطابق الإجمالي والرسم مع السجلات الظاهرة.
